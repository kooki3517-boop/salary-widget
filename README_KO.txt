월급이 자란다 — 갤럭시용 안드로이드 앱 소스 프로젝트

설정: 월급 2,500,000원 / 매월 1일~말일 / 급여일 10일 / 24시간 균등 / 다크 테마
앱 화면: 초당 갱신. 홈 위젯: 시스템 정책에 따라 대략 30분 주기 갱신(정확한 갱신 시점은 보장되지 않음).
위젯을 누르면 앱이 열리며 실시간 금액을 볼 수 있습니다.

주의: 이 ZIP은 완성된 APK가 아닌 Android Studio 프로젝트입니다. APK 생성에는 PC가 필요합니다.

1. PC에 Android Studio를 설치합니다 (developer.android.com/studio).
2. ZIP 압축을 풀고 Android Studio > Open > SalaryGrows 폴더를 선택합니다.
3. Gradle Sync를 진행합니다. Android SDK 35와 Gradle 관련 파일은 Android Studio가 다운로드할 수 있습니다.
4. Build > Build Bundle(s) / APK(s) > Build APK(s)를 선택합니다.
5. 생성된 app/build/outputs/apk/debug/app-debug.apk를 갤럭시에 복사하여 설치합니다.
   갤럭시에서 '출처를 알 수 없는 앱 설치' 권한을 허용해야 할 수 있습니다.
6. 홈 화면 빈 곳 길게 누르기 > 위젯 > '월급이 자란다' > 추가.

개발 환경에 따라 Android Studio 메뉴 이름이 조금 다를 수 있습니다.
이 환경에서는 APK 컴파일/기기 테스트를 수행하지 못했습니다.
