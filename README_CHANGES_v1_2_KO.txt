월급이 자란다 v1.2

v1.1의 기존 위젯 크기, 투명 배경 옵션, 위젯 클릭 시 설정 열기, 아이콘을 유지합니다.

추가: 설정 화면의 4대보험 예상 계산
- 정규직 / 계약직 / 단시간 근로자 선택
- 주당 근로시간 입력 및 저장
- 국민연금, 건강보험·장기요양보험, 고용보험 적용 여부 수동 선택
- 세전 월급 기준 예상 근로자 부담액 표시
- 산재보험 근로자 부담 0원 표시
- 보험료 공제 후 예상액 표시 (소득세·지방소득세 제외)
- 실제 가입 대상 여부는 자동 확정하지 않으며, 입력된 근로 형태와 시간은 참고 정보입니다.
- 기존 세후 실수령액 직접 입력 및 위젯 적립 계산은 변경하지 않습니다.

주의: 보험료는 개인별 보험료 산정 기준, 상·하한, 자격, 비과세 급여, 고지액 및 연도별 요율에 따라 달라집니다. 이 계산은 급여명세서나 공단 고지액을 대체하지 않습니다.
